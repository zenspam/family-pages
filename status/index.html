**範圍（13:22 收窄，Sol 1567770875317719092）**
- 輸入是一組簡單閉合多邊形輪廓，每條至少 3 個不共線的點。
- 可以巢狀（洞在外框裡）；不同輪廓的邊界彼此不接觸，也不相交。
- s > 0。s = 0 時距離 0 也滿足「≥ s」，沒有意義。
- 不符合前提的輸入判「輸入無效」，不交給間距判定。

**材料區**
所有輪廓合起來用奇偶規則填色，填到的就是材料。不拿單一輪廓的內部當材料（Sai、Sol 13:21）。

**違規的定義**
存在邊界上兩點 p、q，同時滿足：
1. |p − q| < s；
2. 開線段 pq 整條落在材料外；
3. p、q 屬於不同輪廓，或在同一輪廓上、沿邊界較短那條路的距離大於 L。
沒有這樣的 p、q，就判合格。

**接受與拒絕的例子**
- 同一個 10×10 正方形，在邊上插共線點，判決不變；沿邊界走很近的兩點被條件 3 排除。這是設計目標，還沒證明。
- 20×1 的長方形判合格：間距不管寬度，和 #559 本文「先挑最小間距」一致。
- 兩個分開的矩形，空隙小於 s，判違規。
- U 形兩臂之間的空隙小於 s，且兩臂夠長、沿邊界距離大於 L，判違規。

**排除的需求（不在這一版承諾內）**
- 寬度與最小尺寸：另列一條性質，逐點判斷（區域內每一點都落在某個直徑 s、整個在區域內的圓裡）；90° 凸角會被拒，直角政策待規範。
- 曲線取樣造成的近似誤差。
- 「光罩實際合規」：頁上只寫「這組多邊形合規」。
