Grok 讀 X 公開帖寫草稿，Gemini Argon（網頁）潤飾文筆；程式核過每個數字與連結都出自草稿。內容未經人工逐句核對。

賽博吳同學說 Revolut 讓大約兩千個工程師改用自建的 GLM 寫程式，把花費壓到幾毛錢。

賽博吳同學 @jaxxwu

他說 Revolut 用 56 張卡自建 GLM 讓大約兩千個工程師寫程式，把 token，也就是 AI 讀寫字的計費單位，成本壓到幾毛錢，讓 Claude Code 和 Codex 變成要例外申請的備用工具。

對你有什麼用。日常寫程式可以先用便宜且跑得通的模型省錢，遇到難題再換回貴的旗艦模型。

indigo @indigox

他轉述 Claude Code 團隊 Addy 的分享，說模型越強越容易讓人放鬆警惕，所以用 Agent，也就是能自己動手執行任務的 AI，要在做事前後自己把關。

對你有什麼用。派任務給 AI 前先寫好目標和完成標準，做完後先看證據再看總結，或是用另一個模型讀執行文件和 log，也就是系統運行紀錄，來雙向檢查。

Addy Osmani @addyosmani

他說團隊在 2.1.317 更新了 Claude Code 裡 Opus 5.5 的 prompt，也就是給 AI 的指令規則，解決之前提別的遊戲名字就被拒絕製作的問題。

對你有什麼用。現在用 Claude Code 做遊戲時，你可以直接說出某個現有遊戲的名字來描述想要的玩法，請它做出同類型的原創遊戲。

TU（gpt源头） @WzZzz25132

他說大家不要只跟 AI 聊天，要改用像 Codex 或 Claude Code 這種能讀取本地檔案和軟體的 Agent。

對你有什麼用。忘記專案進度時，可以直接讓 AI 讀取整個本地資料夾的舊筆記和進度記錄，幫你找出哪裡卡住並安排下一步，幫你省時間。

他轉述網易智企副總經理段毓錚在 2026 世界互聯網大會浙江分論壇的做法，用帝王蟹升級首發的 Agent Team 讓一個 AI 當組長，帶著商務、法務、安全、交付 AI 互相挑合同毛病再彙總。

對你有什麼用。審合同時可以讓不同專業分工的 AI 互相挑錯討論並留下記錄，組長彙總後你再做最後決定，省下自己慢慢檢查的時間。
