李天才｜TianCai @Lniosytest

他說用 AI 寫程式老是翻車的人，要把自己的聊天記錄丟給 AI 總結出踩過的坑，寫進全局 AGENTS.md，這是一種給 AI 看的規則說明書。

對你有什麼用。你可以把讀取權限、檔案路徑索引、驗收標準、不准刪倉庫和不准擅自 push 也就是上傳程式碼的規定寫清楚，避免 AI 亂改或把開發記錄當成源碼傳上去。

Cindy @askmycindy

她分享了他們在自己電腦上驗收程式的流程，把寫完程式和驗收通過分開，每個任務用獨立的 worktree 和分支，也就是各自隔離的工作區，讓 AI 實際操作介面跑通核心場景。

對你有什麼用。你在同時開發很多功能時可以把程式碼和資料隔開，不碰正式環境的資料，並確定程式真的能跑、資料庫能正常讀寫和恢復，而不是只有編譯通過而已。

如意｜Ruyi @ruyi3699

她介紹了 PixelRAG，這是一種不把網頁和 PDF 硬轉成文字，而是直接截圖靠畫面來找資料的工具，她說官方測試宣稱最高有 18.1% 的準確率提升，還宣稱能把 Agent 也就是 AI 助手的 Token 成本，也就是算字數收費的額度壓低約 10 倍。

對你有什麼用。你處理有表格、圖表或複雜排版的檔案時不會弄丟結構，而且她說目前已經預建好 828 萬個 Wikipedia 頁面索引，還有免費 API 也就是程式連接埠，跟 Claude 插件能直接體驗。

棈澧 @hodu382759

他介紹了寫程式的開源 Agent 叫作 Cline，開源就是程式碼公開讓人免費使用，他說這個工具在 GitHub 有 7 萬星，採用 Apache 2.0 協議這種免費授權規則。

對你有什麼用。你可以在 VS Code、JetBrains 或終端機這些寫程式的軟體裡用它改檔案跟跑命令，每一步都要你點同意才執行，還能自己選模型或接自己電腦上的 Ollama 來跑。

ElioEx @elioex0

他說 OpenAI 幫把 Agent 會話放到雲端跑的介面 Agents API 加了後台壓縮功能，並且正在實驗讓模型理解把 CI 修復，也就是自動測試與整理的流程控制在十分鐘內完成的時間感知功能，不過他說原帖沒給到點強制停止的保證。

對你有什麼用。你用這個介面跑長任務時可以在後台完成長對話壓縮，少一次乾等，還能在會話跑著的時候更新工具列表。
